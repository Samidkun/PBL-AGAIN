# 💅 Luxe Nail — Reservation & Service Management System

Luxe Nail is an integrated reservation and service management system designed to streamline nail salon operations. The platform consists of an **Admin Web Application** and a **Mobile Application** for nail artists.  
Customers can make reservations, upload DP (down payment) proof, and complete final payments. Admins validate payments and monitor the entire workflow, while nail artists receive reservation details and carry out the services through the mobile app.  
Every step is synchronized in real-time to ensure an efficient, accurate, and seamless experience.

---

## ✨ Key Features

### 👤 Customer
- Browse available services  
- Make online reservations  
- Upload DP (down payment) proof  
- Track reservation status  
- Complete final payment after service  

---

### 🛠️ Admin (Web)
- Validate DP proof submitted by customers  
- Manage reservations, services, and pricing  
- Monitor service progress from nail artists  
- Handle final payments through the cashier system  
- View transaction history and service reports  

---

### 🎨 Nail Artist (Mobile App)
- Receive validated reservations  
- View service and customer details  
- Follow fixed pricing and selected service packages  
- Update service progress status  
- Submit final service results synced to the admin system  

---

## 🔄 System Flow (Overview)
1. Customer selects a service and makes a reservation  
2. Customer uploads DP payment proof  
3. Admin validates the DP  
4. Reservation data is automatically sent to the nail artist's mobile app  
5. Nail artist performs the service based on the chosen package  
6. Final payment amount appears in the admin cashier system  
7. Customer completes payment  

---

## 🧰 Technologies Used
- **Laravel** — Backend & Admin Web  
- **Blade / Bootstrap** — Web Frontend  
- **Flutter** — Mobile App (Nail Artists)  
- **MySQL** — Database  
- **REST API** — Data synchronization
